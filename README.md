# Starlace

Starlace is a kindergarten game. Nim and Bop help with letters, words, numbers, and shapes.

The lasting copy is published with GitHub Pages from `main`. The address follows the repository name:

- https://sscthulhu.github.io/Learning-Project/
- https://sscthulhu.github.io/starlace/ after the repository is renamed to `starlace`

## Play it locally

```bash
npm install
npm run dev
```

`npm run build` writes the site into `dist`. GitHub Actions sets the address path when it publishes.
